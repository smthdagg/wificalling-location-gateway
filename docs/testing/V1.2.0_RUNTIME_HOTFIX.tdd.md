# v1.2.0-r2 AX6S runtime hotfix evidence

## Scope

This patch release preserves the v1.2.0 integrated Wi-Fi Calling Gateway + WLOC package and fixes the AX6S runtime regressions found during device validation.

## TDD evidence

- RED: the regression suite reproduced the blocking WLOC listener, missing local synthesis default, upstream failure reported as success, and monitor temporary-file leak.
- GREEN: the listener is nonblocking before Tokio conversion; the init script enables the existing local synthetic response path; upstream failures propagate as errors; monitor temporary files are removed.
- Security GREEN: `h2` is pinned to `0.4.16`; `cargo audit --file Cargo.lock` reports no advisories.
- Full gate: `./scripts/ci/verify.sh` passed (69 Python tests, Rust tests, LuCI checks, packaging checks, secret scan, and coverage; line coverage 80.96%).

## Package evidence

- Target: `aarch64_cortex-a53` (AX6S), statically linked AArch64 ELF.
- `wloc-service`: 1,904,800 bytes.
- `wloc-ctl`: 462,792 bytes.
- Package-level monitor cleanup test passed after extracting the IPK.
