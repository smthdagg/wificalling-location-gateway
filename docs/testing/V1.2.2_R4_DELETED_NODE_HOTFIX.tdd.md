# v1.2.2-r4 deleted-node hotfix verification

## Scope

This release remains on the final stable integrated 1.2.x line. It fixes one
auto-follow invariant: a WLOC probe may use only the node explicitly bound to
the followed WCG device. If that device or node no longer exists, the service
must publish no exit IP and no Geo target until the administrator selects and
applies a valid node.

The independently maintained multi-device/2.0 Beta line is not a source,
baseline, dependency, or release input for this repository.

## Redmi AX6S verification

The two UCI files were copied to a temporary backup before mutation. Because
the overlay is constrained, R3 was stopped and removed before the exact R4
AArch64 package was installed. The package hash was verified on the router.

Post-install evidence:

- installed package: `wificalling-location-gateway 1.2.2-r4`;
- WCG sing-box processes: 2; WLOC process: 1;
- generated sing-box configuration valid and WLOC control socket present;
- normal auto-follow state: `intercepting`, exit `verified`, Geo `fresh`;
- available memory: approximately 23 MiB; available overlay: approximately
  14.5 MiB;
- both UCI configuration files matched their pre-install backups.

For the destructive-edge regression, the sole device binding was temporarily
changed to a guaranteed-missing node under an automatic restoration trap. The
refresh result was exit `unavailable`, Geo `unavailable`, no exit IP, no
latitude, and the explicit missing-node error. No unrelated outbound was used.
After restoring the original configuration and restarting both services, the
exit returned to `verified` and the Gateway configuration matched the backup.

No node endpoint, credential, precise location, CA private key, or raw device
traffic was collected in this evidence.

## Rollback

The R3 package and both backed-up UCI files remain the rollback inputs. On a
low-storage AX6S, stop both services, remove only the integrated R4 package,
restore the two UCI files, install the hash-verified R3 AArch64 package, and
restart WCG before WLOC.
