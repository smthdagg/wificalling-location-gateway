# v1.2.2-r3 three-platform release verification

## Scope and stable baseline

This release stays on the stable `v1.2.2-r3` line. It does not include the
multi-device Beta branch. The AArch64 package already published for the tag is
the immutable base input for the x86 packaging process, pinned by SHA-256.

## TDD evidence

The release-builder regression test was added first and failed with:

```text
FAIL: release builder must accept a hash-pinned stable integrated package as its 1.2.x base
```

RED checkpoint: `8ec2722 test: require stable integrated release base`

The builder was then restricted to the legacy Gateway identity or the stable
integrated identity, with explicit 1.7.x/1.2.x version forms and mandatory
SHA-256 validation. The same test then passed.

GREEN checkpoint: `ad072eb fix: accept stable integrated release base`

The final `./scripts/ci/verify.sh` run passed all repository gates: 69 Python
tests, all Rust unit/integration suites, formatting, Clippy, secret scan,
dependency/advisory/license policy, release-size checks, and 81.06% Rust line
coverage. The dependency audit reported only the already-accepted duplicate
crate-version warnings and no advisory, license, source, or ban failure.

## Redmi AX6S verification

The exact AArch64 release asset had already been installed after removing the
superseded RC package to respect the router's limited overlay space. The two
UCI configuration files were backed up and preserved during that operation.

On 2026-08-23 the router reported:

- installed package `wificalling-location-gateway 1.2.2-r3`;
- WLOC process running, control socket present, phase `intercepting`;
- Gateway monitor and sing-box running, generated configuration valid;
- one active device policy and four configured nodes (counts only; no private
  values were collected);
- WLOC and Gateway monitor PIDs stable during the observation window;
- approximately 15 MiB available overlay storage at the end of verification.

The earlier runtime-hotfix gate for this same package also completed five
independent local TLS/HTTP2 WLOC requests with HTTP 200. Fresh carrier Wi-Fi
Calling and iPhone location actions remain client-triggered checks; package
installation cannot create that traffic by itself.

## Rollback

Back up `/etc/config/wificalling-gateway` and `/etc/config/wloc-service` before
changing packages. On a storage-constrained AX6S, remove only the old package,
install the matching AArch64 IPK, then confirm both files still exist before
restarting services. Never install an x86_64 asset on AX6S or rename an IPK to
APK.
