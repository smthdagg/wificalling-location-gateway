# Wi-Fi Calling Location Gateway 1.0.0

This is the first stable release of the standalone, integrated OpenWrt product.

## Download the one package for your platform

| Platform | Asset |
|---|---|
| Redmi AX6S / mt7622 / AArch64 | `wificalling-location-gateway_1.0.0-1_aarch64_cortex-a53.ipk` |
| OpenWrt 24.10 / iStoreOS 24.10 / x86-64 | `wificalling-location-gateway_1.0.0-r1_x86_64.ipk` |
| OpenWrt 25.x / x86-64 | `wificalling-location-gateway-1.0.0-r1.apk` |

Verify the selected file against `SHA256SUMS` before installation. Install it
directly over an earlier component build; do not remove the old package first.
Both Gateway and WLOC UCI configuration files are retained as conffiles.

Every file in `SHA256SUMS` was installed from the exact release directory in a
pinned Docker rootfs. The AX6S IPK ran in official AArch64 OpenWrt 24.10.5;
the 24.x x86-64 IPK ran in OpenWrt 24.10.8 and iStoreOS 24.10.5; the native APK
ran in OpenWrt 25.12.3. Every case started the service, created the control
socket, and returned a valid `wloc.service/v1` status response.

The exact final AX6S asset was also installed over ImmortalWrt 24.10.6. Both
existing UCI hashes were preserved, both services started, the Wi-Fi Calling
settings rendered, and LuCI Manual → Auto → Manual completed without error.

## Highlights

- Unified Wi-Fi Calling Gateway 1.7 and router-local WLOC workflow.
- Automatic location follows the selected device's node exit; manual mode
  supports search, coordinates, and saved locations.
- iPhone CA profile download, fingerprint verification, and local-only key
  storage.
- Exact traffic isolation, bounded TLS/H2 processing, fail-open behavior, and
  privacy-preserving status/logging.
- Reproducible Rust/OpenWrt builds and a four-environment installation matrix
  covering every release asset.

## Prerequisites

The firmware must provide LuCI/rpcd, sing-box, firewall4/nftables, `ip-full`,
and the nft TPROXY/socket kernel modules. The package is self-contained with
respect to the two application components, but it does not replace normal
OpenWrt system facilities.

## Upgrade and rollback

Back up `/etc/config/wificalling-gateway`, `/etc/config/wloc-service`, and the
router configuration archive. Upgrade by installing the new file directly.
If rollback is required, reinstall the prior architecture-matching package;
do not delete the UCI files or local CA unless intentional reset is required.

Read the [Chinese guide](../WIFICALLING_WLOC_TUTORIAL_ZH.md) or
[English guide](../WIFICALLING_WLOC_TUTORIAL_EN.md) before enabling WLOC on a
dedicated test iPhone. A network `ASSURED` observation is not carrier activation
proof, and WLOC target coordinates are not emergency-call location evidence.
